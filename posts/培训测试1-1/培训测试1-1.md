`__gmpz_init_set_str` 是 GNU MP（GMP）大数运算库中的一个函数，它的核心功能是初始化一个多精度整数变量，并同时将一个字符串按照指定进制转换为数值赋值给它。`__gmpz_init_set_str` 是 `mpz_init_set_str` 函数在GMP库内部使用的别名。

```C++
int mpz_init_set_str (mpz_t rop, const char *str, int base);
```

它接收三个参数：

1. `mpz_t rop`：要初始化的多精度整数变量。

2. `const char *str`：包含数字的、以空字符结尾的C字符串。

3. `int base`：字符串 `str` 所使用的进制数。

`__gmpz_powm` 是 GNU MP（GMP）大数运算库中的一个核心函数，用于执行模幂运算。它也是 `mpz_powm` 函数在GMP库内部使用的别名。简单来说，它能够高效地计算一个大数的 “幂” ，然后再对另一个大数 “取模”。

```C++
void mpz_powm (mpz_t rop, const mpz_t base, const mpz_t exp, const mpz_t mod);
```

它接收四个参数，所有参数的类型都是 `mpz_t`，即GMP的多精度整数类型：

1. `mpz_t rop`：输出参数，用于存储最终的计算结果。

2. `const mpz_t base`：底数。

3. `const mpz_t exp`：指数。

4. `const mpz_t mod`：模数。

# -*- coding: utf-8 -*-
"""
getiv.py — 用 Python 3.11 直接加载 wp.pyc 模块，获取 IV。

原理：
  1. wp.pyc 模块顶层会自动执行 main()（它内部 build 出真实的 9x9 邻接矩阵，
     跑 Dijkstra 最短路 yuanshen(array,1,8) 得到路径 -> 拼成 IV）。
  2. main() 最后调用 qidong(flag, key, IV)，而 qidong 内部执行
        pyDes.des(key, pyDes.CBC, IV, pad=None, padmode=pyDes.PAD_PKCS5)
     第 3 个位置参数就是 IV。
  3. 所以只要在 import 前把 pyDes.des 包一层截获第 3 个参数，加载 wp.pyc 后
     就能拿到真正的 IV —— 完全不用手动抠数组。

用法（在 ezpython 目录下）：
    py -3.11 getiv.py
"""
import importlib.util
import importlib.machinery
import os
import sys
import builtins

# ---------- 1. 确保 pyDes 可用（只需 CBC / PAD_PKCS5 / des 三个符号） ----------
try:
    import pyDes                       # 真实 pyDes（若已安装）
except ImportError:
    # 自带的极简替身：足够让 main()->qidong() 跑通，IV 在下一步截获
    class _FakeCipher:
        def encrypt(self, data):
            return b'\x00' * 32        # 结果无所谓，我们只要 IV
    class _FakePyDes:
        CBC = 0
        PAD_PKCS5 = 1
    pyDes = _FakePyDes()
    def _des(key, mode, iv, *a, **k):
        return _FakeCipher()
    pyDes.des = _des
    sys.modules['pyDes'] = pyDes

# ---------- 2. 包一层 pyDes.des：截获 qidong 传来的 IV ----------
_real_des = pyDes.des
_captured = {}
def _fake_des(key, mode, iv, *args, **kwargs):
    _captured['iv'] = iv
    return _real_des(key, mode, iv, *args, **kwargs)
pyDes.des = _fake_des

# ---------- 3. 模块顶层会自动调用 main()，先替换 builtins.input 以免阻塞；并屏蔽其 print 噪音 ----------
_calls = {'n': 0}
def _fake_input(prompt=''):

    # 第 1 次询问是 key（DES 密钥，头提示给出 yuanshen，正好 8 位）；其余是 flag 占位

def _fake_print(*a, **k):           # main() 的 yes/bad 提示不影响取 IV，静音掉
    pass
builtins.print = _fake_print

# ---------- 4. 直接加载 wp.pyc（exec 时 main() 自动执行 -> 算出最短路 -> 触发 qidong -> 截获 IV） ----------
here = os.path.dirname(os.path.abspath(__file__))

spec = importlib.util.spec_from_loader(loader.name, loader)
module = importlib.util.module_from_spec(spec)
loader.exec_module(module)

# ---------- 5. 输出截获的 IV ----------
