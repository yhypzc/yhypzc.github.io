当然要注意到这个式子

```C++
v32 = i * (__int128)(__int64)0x8421084210842109LL;
          enc_arg4 = i - 31 * ((*((_QWORD *)&v32 + 1) + i) >> 4);
```

编译器对取模运算 `i % 31` 的自动优化结果。在没有硬件除法或除法指令很慢的平台上，编译器会用乘法、移位和减法来高效计算余数。

假设 i 是 64 位无符号整数，想求 `i % k`。常用的优化公式为：

```C++
q = floor(i / k)
r = i - k * q
```

编译器会选择一个魔数 `M = ceil(2^64 / k)`然后计算商。

计算 128 位乘积 `i * M`。

取乘积的高 64 位，记为 `high`。

由于某些除数的魔数可能产生 ±1 的误差，编译器加入校正：`q = (high + i) >> 4`

最后用 `i - k * q` 就得到了余数 `enc_arg4`，即 `i % 31`

再来看：

```C++
enc_arg1 = 8 * (i - (i & -4uLL));
```

等价于

```C++
enc_arg1 =(i % 4) << 3
```

文件前20字节是：

```
50 41 50 52 04 04 26 20 c6 00 00 00 26 59 41 31 d2 c4 17 5a
```

所以解密算法相当于：

```C++
payload[i] = payload[i] ^ (-(((i % 4) << 3) < 0x20)) & (__ROL4__(0x31415926, i % 31) >> ((i % 4) << 3)) ^ (9 * i + 65)
```

`i % 4` 的范围是 `0~3`，所以 `(i % 4) << 3` 的范围是 `0, 8, 16, 24`，永远小于`0x20`

在无符号运算中就是 `-1`（即所有位为 1）

这个掩码与任何数按位与（`&`）结果不变，所以整个 `-(((i % 4) << 3) < 0x20) & (...)` 可以简化为 `(...)`。

继续优化：

```C++
payload[i] = payload[i] ^ (__ROL4__(0x31415926, i % 31) >> ((i % 4) << 3)) ^ (9 * i + 65)
```
