# 前置工作

无法出目录，直接仿真。仿真两个盘全勾上。强行选“其他”，因为镜像自带操作系统了，网络开NAT。

![9F1F064B\-4B72\-4876\-92EC\-E7528680C077\.png](图片和附件/9F1F064B-4B72-4876-92EC-E7528680C077.png)

CPU开多一点，直接开仿，密码123456进去了。

![B0B41DFE\-187E\-4443\-802B\-C385FD484F1E\.png](图片和附件/B0B41DFE-187E-4443-802B-C385FD484F1E.png)

这里有坑！实际上自己在容器里面,容器的ssh别开，不然后续端口占用很麻烦：

```Assembly language
cat /proc/1/cgroup
```

如果回显有docker，说明在容器里面。

`Ctrl + Alt + F2` 是在 Linux 物理机或虚拟机上切换 TTY（虚拟终端） 的快捷键，直接退出容器

![1C51AC65\-ED09\-47b0\-AF7D\-11AA5E602E99\.png](图片和附件/1C51AC65-ED09-47b0-AF7D-11AA5E602E99.png)

这才是宿主机，密码123456。

查看ip

![BD0F1535\-84DE\-4b76\-9ACE\-BD83B558AC35\.png](图片和附件/BD0F1535-84DE-4b76-9ACE-BD83B558AC35.png)

然后安装ssh

```Assembly language
sudo apt update
sudo apt install openssh-server
sudo systemctl status ssh 
sudo ufw allow ssh
```

装好ssh，即使输入正确的用户名和密码但认证失败。

![ED7552AA087F42e8A61F863C81387F3B\.png](图片和附件/ED7552AA087F42e8A61F863C81387F3B.png)

这是怎么回事？FinalShell 成功建立了加密通道，但在最后一步的“用户认证”环节失败了。

这是因为有些情况下，有时为了安全，SSH服务端会关闭密码登录。需要检查服务端配置文件 `/etc/ssh/sshd_config`

```Assembly language
cat /etc/ssh/sshd_config
vim /etc/ssh/sshd_config
```

![7460EBB6\-FD04\-4231\-8103\-28DB44440D53\.png](图片和附件/7460EBB6-FD04-4231-8103-28DB44440D53.png)

去除配置文件的\#号

```Plain Text
PasswordAuthentication yes
PermitRootLogin yes
```
